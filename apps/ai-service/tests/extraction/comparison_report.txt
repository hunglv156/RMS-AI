Implementation
--------------
Public API: app.extraction.extract_document(bytes, ocr_lang='eng', dpi=200,
limits=ExtractionLimits()). Frozen result dataclasses include page number,
half-open normalized Unicode character offsets, method, optional OCR confidence,
page/document flags, extractor and normalization versions, and tool versions.
Text-layer content is meaningful if it has any alphanumeric character; this keeps
short names usable. Hidden text is retained, with flags for near-white text,
font size <=1 point, text matching a containing vector fill, invisible rendering
mode, and near-zero opacity. These heuristics are not a complete detector for
image backgrounds, gradients, occlusion or adversarial layouts.

Tesseract is called through subprocess with PNG bytes on stdin and TSV on stdout:
PyMuPDF already renders PNG, so this avoids Pillow/pytesseract dependencies and
allows explicit per-page timeouts. TSV gives word confidences and line/paragraph
boundaries. Word confidences below 60 on average trigger low_ocr_confidence;
blank OCR output triggers empty_page, and an entirely blank document gets no_text.
Default limits: 25 MiB, 100 pages, 25 million rendered pixels per page, 60 seconds
per OCR call. Parsing still belongs in an isolated worker for untrusted input.
No network is used by the extraction module or comparison script.

Normalization is norm-v1: preserve words, Unicode and internal spacing; unify
CRLF/CR to LF, trim line-end whitespace and outer blank lines, collapse blank-line
runs. Nonempty pages have exactly two newlines between them; empty pages have
zero-width spans and introduce no additional separators. This keeps the final
text idempotently normalized while retaining every page in metadata. OCR itself
can misrecognize content and reading order; normalization makes no corrections.
